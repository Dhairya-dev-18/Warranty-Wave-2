# Warranty Wave frontend

This folder contains the Angular 21 application. For the complete MySQL, backend, environment, and startup instructions, see the repository [README](../README.md).

Run `npm ci` and `npm start` from this folder. The Angular development server runs at `http://localhost:4200` and forwards `/api` requests to `http://localhost:8080` using `proxy.conf.json`. Run `npm run build` to create the production bundle in `dist/frontend`.
